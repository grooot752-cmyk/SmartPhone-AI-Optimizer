AI PHONE DR

An Android phone maintenance and backup assistant.

Target device

- Android 8.1 (API 27) and newer
- No root required
- Optimized for 3GB RAM devices

Planned features

1. AI Cleaner – identify junk files and help the user review files before deletion.
2. Performance Assistant – storage analysis, battery information and safe optimization guidance.
3. Google Drive Backup – user-authorized backup and restore.
4. Online and Offline Assistance – basic offline functions with optional online AI features.

Safety and privacy

- Never delete personal files automatically.
- Ask permission before accessing or backing up files.
- Let users choose backup folders.
- Do not claim to boost hardware performance beyond Android's capabilities.

Build

Android application using Java and Gradle.
